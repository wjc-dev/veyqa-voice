# Veyqa Voice 0.3.0

- 听写引擎重写为原生应用，菜单栏、设置页和快捷键保持原样。
- 按需收音：空闲时不占用麦克风，按键后更快进入录音状态。
- 安装包从约 46 MB 降到约 12 MB（ZIP 约 5 MB），冷启动不再加载 Python 运行时。
- 常驻内存与空闲 CPU 按原生引擎重新设计，空闲时不占用麦克风。
- 内置服务继续免费使用，无需注册或填写 API Key；已有个人 Key、模型和词汇保存在本机并原样保留。
- 升级沿用同一应用标识、数据目录和签名身份，麦克风、辅助功能、输入监控授权无需重新设置。
- 保留录音存档、恢复未写入文本、纠错学习、模型目录和自动更新。

## 更新

在“设置 → 通用 → 应用”点击“检查更新”，或重新下载安装包覆盖“应用程序”中的旧版。配置与授权保留，无需先卸载。

Homebrew 用户：

```bash
brew update
brew upgrade --cask wjc-dev/veyqa/veyqa-voice
```

需要 Apple Silicon、macOS 13+。
