TERMINAL 
$ brew install --cask wjc-dev/veyqa/veyqa-voice
  1. 1

    连接语音服务

    默认千问。在应用里获取并填写 API Key，点击“检查连接”。

  2. 2

    确认权限

    按引导开启麦克风、辅助功能和输入监控，然后保存并重启。

  3. 3

    按住右 Option，说话

    把光标放进文本框，按住说、松开写。快捷键可自定义；升级保留原设置。
