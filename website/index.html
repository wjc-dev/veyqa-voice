  1. 1

    连接语音服务

    默认千问。按应用里的获取步骤创建并粘贴 API Key，点击“连接并继续”，成功后自动保存。Key 是什么？

  2. 2

    确认权限

    按应用引导开启麦克风、辅助功能和输入监控权限。授权由你在系统设置里亲自确认。

  3. 3

    先在应用里试一句

    点击试用文本框，按住键盘右侧 Option 说话，松开结束。看到文字后完成设置，再到其他 App 使用。升级保留原配置。

ONE-TIME SETUP

API Key，只需配置一次。

它是语音服务的访问密钥，不是登录密码。Veyqa 不出售额度，也不收集你的 Key。

  1. 1

    登录阿里云百炼

    用自己的账号打开百炼 API Key 页面 ↗，按控制台提示开通服务。

  2. 2

    创建并复制 Key

    选择所用服务的地区后创建 Key。应用默认中国内地（北京）；其他地区在高级设置中调整。不要把 Key 发给聊天或 Agent。

  3. 3

    回到 Veyqa 粘贴

    点击“连接并继续”。API 调用可能产生费用，以百炼的账户额度与计费说明为准。官方详细教程 ↗
