  1. 1

    连接语音服务

    默认“内置服务”，无需注册或填写 Key，点击“连接并继续”。 也可切换个人 API，已有配置保持不变。使用自己的 Key ↓

  2. 2

    开启权限

    按引导开启麦克风、辅助功能和输入监控。返回 App 后自动检查；系统要求重新打开时，按提示操作即可。

  3. 3

    试一句，完成设置

    点击试用文本框，按住右 Option 说话，松开写入。完成后即可在其他 App 使用。点击菜单栏图标打开设置，也可从“应用程序”再次打开。

ONE-TIME SETUP

也可以使用
个人 API Key。

内置服务无需填写 Key。想使用其他模型时，可切换自己的语音服务账户；Key 保存在本机，费用由对应服务商收取。

  1. 1
    阿里云百炼API Key →

    打开百炼，登录账号

    进入百炼 API Key 页面 ↗，按控制台提示开通语音服务。

  2. 2
    地区：中国内地（北京）创建 API Key ＋

    创建 Key，然后复制

    应用默认中国内地（北京）。其他地区可在“高级设置”调整。Key 请仅填写在应用的凭证输入框。

  3. 3
    API Key ············连接并继续 →

    粘贴到 Veyqa，检查连接

    点击“连接并继续”，成功后自动保存。随后开启权限，在试用文本框完成首次输入。

SPEECH ENGINES

选择适合你的语音服务。

内置服务使用千问 3.1 Message，边说边显示，默认保留原话，费用由 Veyqa Voice 承担。使用个人 API 时，可选择千问、豆包模型并刷新官方目录。音频直接发送至所选语音服务，录音存档默认关闭。

默认 · 千问

Qwen Audio 3.0 / 3.1 ASR

流式识别，边说边查看预览。可选持续转写或短句听写，支持多语种及方言、热词增强。

模型说明 ↗
可选 · 豆包

豆包语音识别

使用火山引擎语音账户，支持流式转写与词汇提示。已有豆包凭证可直接在应用中切换。

模型说明 ↗

也支持自定义 OpenAI 兼容语音服务：填入 API 地址、Key 和模型型号，录音结束后转写。
