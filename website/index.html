A LITTLE HELP

常见问题

下载后怎么开始？⌄

打开 DMG，将 Veyqa Voice 拖入 Applications（应用程序），再打开 App。选择内置服务，点击“连接并继续”，按引导开启麦克风、辅助功能和输入监控；回到 App 自动检查权限后，在试用文本框按住右 Option 说一句即可。

首次打开提示“无法验证开发者”？⌄

当前版本尚未经过 Apple 公证。从官网下载后，在“系统设置 → 隐私与安全性”点击“仍要打开”。Apple 打开说明 ↗

如何配置个人 API？⌄

打开“设置 → 语音服务 → 个人 API”，选择供应商，填写凭证并检查连接，再选择模型。

千问：在百炼创建 API Key，粘贴到 App。默认使用中国内地（北京），其他地区可在高级设置调整。获取千问凭证 ↗

豆包：在火山引擎开通语音识别服务，按应用内帮助填写 App ID 和 Access Token。豆包接入说明 ↗

自定义：填写兼容音频转写接口的 Base URL、Key 和模型型号。Key 保存在本机，费用由对应服务商收取。

内置服务需要付费或填写 Key 吗？⌄

推广期间免费体验，无需填写 API Key。内置服务使用 Qwen Audio 3.1 Message，费用由 Veyqa Voice 承担。音频直接发送至所选语音服务，本地录音存档默认关闭。添加专有词汇可提升识别概率。

如何更新？⌄

在 App 设置中点击“检查更新”，下载并重新打开，Key 和配置保留。0.2.8 及更早版本先退出 App，用新版 DMG 替换一次。Homebrew 更新方法 ↗
