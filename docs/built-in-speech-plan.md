# 内置语音服务执行计划

依据：`docs/superpowers/specs/2026-10-20-built-in-speech-design.md`，用户已审阅批准。

1. 核验官方临时 Key 与 3.0 Streaming：已完成静音任务验证，后续补真实语音与冷热缓存对比。
2. 创建只允许 3.0 Streaming 的推广专用 Key；配置其 100 元平台月预算、80% 提醒和达预算停用。未核验前不开放签发。
3. 实现独立轻量凭证服务、匿名设备、幂等用量、普通设备额度、速率限制和停发开关；覆盖额度及异常用例。
4. 客户端实现内存凭证缓存、合并预取、有界连接等待、过期及故障处理、用量待补报；老配置继续走原自带 Key 路线。
5. 设置页提供免费内置服务与自带 Key 的清晰切换、模型和余量；新用户免填 Key 完成首次输入。
6. 隔离部署到 kms-hk，检查 HTTPS、监控服务不受影响、无敏感日志；验证专用平台预算覆盖实际临时凭证调用。
7. 修复 Dock 图标留白和更新窗口引发健康检查误恢复的问题；完整回归、性能、真实听写与升级测试。
8. 通过验收后提交并推送 GitHub，上传实际签名附件，最后同步官网、appcast 与 Homebrew；公开下载校验通过才报完成。

本计划扩展原更新计划的范围，原“本轮不开发托管 API、额度”已被用户后续明确指令替代。支付与登录仍不在本轮范围内。
