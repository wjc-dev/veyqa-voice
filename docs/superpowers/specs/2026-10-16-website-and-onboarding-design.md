# Veyqa Voice 官网与首次使用设计

日期：2026-10-16
状态：聊天方案与书面设计均已获用户确认，进入实现与验收。

## 目标

让新用户迅速理解产品、安装并开始听写。官网和 README 面向用户，不再用开发过程细节作为产品介绍。官网、源码和 Homebrew 安装包在测试后同步发布。

## 官网

- 静态 HTML、CSS、JavaScript，源码放在 `website/`；无后端、账号、统计追踪、第三方字体或 API Key 输入框。
- 使用 GitHub Pages，预期地址 `https://wjc-dev.github.io/voxtype/`。仅部署网站目录，不把开发文档或整个仓库当作网站产物。
- 深色底、冷蓝点缀、大留白，兼顾桌面和手机；有限装饰，不使用持续闪烁或高耗能动画，尊重减少动态效果设置。
- 顶部：Veyqa Voice 品牌、安装入口、GitHub 链接。
- 首屏：「说出来，即刻输入。」配简洁语音转文字示意，示意内容明确不是识别精度或速度承诺。
- 产品介绍：按键听写、不替换输入法、不默认 AI 润色；支持千问和豆包。不开列内部守护、签名或 CPU 调试细节。
- 安装：Homebrew 命令复制按钮、发行页下载入口、Apple Silicon / macOS 13+ 要求。
- 开始使用：填写自己的 API Key、确认权限、按住右 Option 说话并松开写入。
- Agent 入口：一键复制完整安装配置提示词；同时允许展开、选中和手动复制。复制失败不能显示“复制成功”，状态提示须能被辅助技术读取。
- 页脚保留简短必要说明：Preview 尚未公证、语音发送到所选云服务、API 费用由服务商收取。错误反馈指向 GitHub Issues。

## Agent 提示词边界

提示词要求 Agent 检查硬件和系统、使用官方 Homebrew tap、核对版本和下载校验值、保留旧配置并避免多版本同时运行。本机固定签名安装不可被公开包静默覆盖。

新 Key 和系统权限由用户本人填写或确认；不得索取或输出凭证，不绕过 Gatekeeper、隔离属性或公司终端防护。不承诺全自动绕过系统确认。最后在空白文稿进行三轮真实输入验证，而不是仅检查进程存在。

## README

中英文 README 同步精简为：产品简介、官网、安装、三步使用、必要限制、反馈与许可证。保留原项目归属和许可证信息。

后台恢复、文字恢复实现、开发签名、低占用测量、源码构建与调试验收移入 `docs/development.md`，README 只留一个开发文档链接。历史验证记录继续保留，不作为用户阅读主线。修正旧版本文案，安装说明与发布包一致。

## 默认右 Option 与配置兼容

- 新安装默认右 Option；操作方式为按住说话、松开完成。需要麦克风、辅助功能和输入监控权限。
- Python 默认值、资源配置模板、模板缺失时的回退、Swift 设置默认值及权限判断保持一致。
- 保留原有组合键和单键选项；组合键依然按需使用系统注册且不额外要求输入监控。
- 既有用户的快捷键、操作方式、凭证、词汇和其他配置不覆盖。已有但未显式填写快捷键的历史配置保留原先有效默认语义，避免因升级默默变更。
- 不更换本机固定签名身份，不重置权限，不改变识别模型、音频流程或默认增加润色。

## 发布与验证

计划发布 0.2.3 Preview（构建 206），不覆盖或重写已经发布的 0.2.2 资产。

发布前完成：

1. 隔离数据目录运行 Python 回归测试，验证新用户默认、已有配置保留、历史配置缺字段及权限需求；执行 Swift 编译/类型检查。不在本机执行曾触发安全软件拦截的临时原生测试程序。
2. 浏览器检查桌面与窄屏布局、键盘可操作性、两个复制按钮、失败回退、安装链接和 Agent 提示词内容；不读取或改写用户真实剪贴板内容用于日志输出。
3. 本机包和公开包分别构建，检查版本、签名结构、包内无用户凭证和私钥。保留现有固定签名和配置；如更新本机，先备份并在空闲时操作。
4. 发布 GitHub Preview，核对远端附件摘要后更新 Homebrew 版本和 SHA-256，实测下载校验；不以下载成功冒充新机器安装与听写成功。
5. 测试通过后部署 GitHub Pages，检查公开地址和页面资源；所有入口指向实际已发布版本。若部署权限或安全策略阻止发布，报告具体阻塞，不绕过限制。

完成证据包括：源码提交、测试结果、公开官网 URL、GitHub Release URL、Homebrew 远端版本及下载校验、本机配置保留情况。长期兼容和零缺陷不在保证范围内。
