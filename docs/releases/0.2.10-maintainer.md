# 0.2.10 发布约束

本轮用户明确批准将推广专用长期凭证随公开安装包分发，并要求恢复统一自动更新。客户端中的凭证可提取，编码不是保密措施；不将它写入源码、日志、网页或 README。现有个人凭证和配置不变。

- 分发标记：`public-promotion`，与隔离的 `private-trial` 区分。
- 构建须同时显式设置 `VEYQA_PUBLIC_RELEASE=true`、`VEYQA_PUBLIC_PROMOTION=true`，并提供 `VEYQA_PRIVATE_TRIAL_PAYLOAD`。产物保存在忽略的 `outputs/` 内。
- 使用固定本机代码签名和既有 Sparkle Ed25519 身份；公开 appcast、ZIP 和安装后的 App 要匹配。
- 发布 appcast 必须传 `--allow-public-promotion`。私测包仍禁止进入公开更新源；公开推广包必须带正式 HTTPS 更新地址、签名验证和每日检查配置。
- 默认自动检查、手动确认安装，不在听写期间强制重启。后续版本沿用此渠道和签名。
- 推广凭证只允许千问 3.0 Streaming。此直连方案不实现每设备 100 分钟额度，也不通过升级强制撤销旧包中的凭证；停用须在服务商端撤销凭证。
- 新安装默认推广语音；已有用户保留个人路线，可手动切换。音频直连百炼，推广调用费用由分发者承担。

发布顺序：构建及回归测试 → 包审计和直连识别 → GitHub 附件上传与哈希核对 → 签名 appcast/官网 → 本机实际更新验证 → Homebrew。
