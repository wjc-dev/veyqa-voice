# Veyqa Voice 0.2.10 · 构建 224

- 推广期间免注册、免填 Key，使用千问 3.0 Streaming；音频直连百炼。
- 保留“自己的 API”选项，升级不覆盖已有 Key、模型、快捷键和词库。
- 推广语音与个人 API 使用同一更新渠道：默认每日检查新版，点击更新后安装并重新打开。
- 修饰键防误触：Command+A/C/V 等组合键不会作为单独语音快捷键提交；按住模式中途形成组合键会取消该次输入。
- Dock 图标尺寸与原生设置交互改进。

需要 Apple Silicon、macOS 13+。当前为尚未经过 Apple 公证的 Preview，首次打开请按官网引导完成系统确认与权限设置。
