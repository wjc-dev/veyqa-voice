# Veyqa Voice 0.2.9 Preview

- 新增应用内检查更新、下载安装和重新打开；默认每天检查新版。
- 调整 Dock 图标留白和边框，视觉尺寸更协调。
- 改进更新窗口打开期间的后台健康检查。
- 保留模型选择、API 凭证显示与复制、整行展开等设置交互。

本版使用你自己的千问、豆包或自定义服务凭证。Key 和配置在升级时保留。

0.2.8 及更早版本请先用新版 DMG 替换，或退出 App 后执行：

```sh
brew update
brew upgrade --cask wjc-dev/veyqa/veyqa-voice
```

升级后可在“设置 → 通用 → 应用”中检查后续更新。

支持 Apple Silicon、macOS 13 及以上。此 Preview 尚未经过 Apple 公证；首次安装与旧签名迁移的权限提示，按[官网指引](https://wjc-dev.github.io/voxtype/#safety)操作。
