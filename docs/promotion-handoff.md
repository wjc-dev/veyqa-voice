## 2026-10-20：防误触与推广流程后续代码（未发布）

- 单修饰键切换模式在独立松键后触发；Command+A/C/V/Q/Tab、其他修饰键组合不触发。
- 按住模式有 180 ms 组合键判定期；随后出现组合键则取消该次语音，不提交文字。
  不能预知用户是否会在很久以后按第二个键，因此长按修饰键后才组合时可能短暂出现录音状态。
- 监听恢复、快捷键捕获和设置切换会取消尚未触发的候选；丢失普通键松键事件时会重新核对物理状态，不永久阻塞后续听写。
- `config/release-features.json` 是 Python 主程序与 Swift 设置的共同发布开关，
  当前 `builtin_speech=false`。环境变量不能绕过该开关。
- 开关开启的构建中，新用户默认免费语音；已有个人凭证及明确选择保持个人模式。
  免费连接检测不依赖已经保存为免费路由，支持从个人服务切换后先检测再保存。
- 免费服务使用专用账号签发的临时凭证，音频直连百炼；客户端不包含长期 Key。
- 用量记录不再截断为最后 128 条；按 32 条分批补报。
  补报失败保留原记录，续领凭证前必须完成同步；并发新增用量不会被旧的响应覆盖。
- 缓存按上海自然月失效；预算/服务停用响应会清除缓存；凭证服务请求不跟随 HTTP 重定向。
- 自动测试：`python -m pytest test -q`，358 项通过（28.53 秒）。
  包括真实 localhost HTTP 服务联调、模拟云端凭证、流式发送长度限制、取消后的用量及临时 Key 清理。
  没有使用真实收费接口或开启远程签发。
- `./build-native-settings.command` 编译及签名验证通过；`git diff --check` 通过。
  尚未替换 `/Applications` 中的应用，未发布新 Release、官网或 Homebrew。
